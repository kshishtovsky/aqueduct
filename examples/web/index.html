🌊 Aqueduct WebTransport Example

This page connects to a running Aqueduct broker via the browser's native WebTransport API (HTTP/3 + QUIC). It opens a bidi stream and sends a CmdSubscribe frame; messages published on the same topic over any transport (native QUIC, another WebTransport client, the cluster mesh) are echoed back in the log.

The wire protocol is the same binary frame used by native clients — no JSON, no protobuf, no parsing.

1. Connection

disconnected

2. Subscribe to a topic

The browser opens a WebTransport bidirectional stream and writes a single CmdSubscribe binary frame. Any subsequent binary frames arriving on the same stream are parsed and rendered.

3. Publish a message

Each click opens a NEW WebTransport bidi stream and writes a single CmdPublish frame. The frame bytes match the broker's native QUIC wire format — the gateway doesn't translate or reformat.
